Objetivos de la Clase

Este proyecto está diseñado para guiar a los estudiantes en la creación de aplicaciones web completas utilizando el ecosistema moderno de Python:

1. Backend Asíncrono

Aprender los fundamentos de FastAPI, async/await, tipado con Pydantic y rendimiento de última generación.

2. Frontend Dinámico

Diseñar interfaces amigables utilizando Jinja2, Bootstrap 5 y llamadas asíncronas con JavaScript.

3. Contenedores y DevOps

Entender cómo funciona un Dockerfile, la construcción de imágenes y cómo empaquetar una aplicación para la nube.

4. Despliegue con Coolify

Configuración de despliegue continuo (CI/CD), variables de entorno, Traefik y gestión de dominios en un VPS.
